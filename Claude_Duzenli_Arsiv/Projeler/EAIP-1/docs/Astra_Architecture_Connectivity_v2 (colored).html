v2 changes: 4 new data quality & governance components (green border) sit between the pipeline layer and storage layer. LLM Enrichment Service uses LiteLLM for AI-powered data curation (document classification, entity extraction, quality scoring). All orchestrated by existing Airflow — no new orchestration tools needed.
