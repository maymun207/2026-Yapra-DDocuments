Hybrid reasoning is the spine

One pattern serves insurance, Galip Usta and CWF: the LLM extracts and ranks; deterministic rules decide and write, with a full audit record. The same engine produces the IATF/AS9100 SPC audit PDF and the Türk Re Takip classification.

Channel Adapter = day-one WhatsApp + more

WhatsApp (text, interactive buttons, voice via Whisper) is live in Phase 0 and shared by every product. Widget, Outlook, web chat and Teams plug into the same Channel Gateway — one brain, many mouths.

IoT-Ignite owns the edge

No edge platform is built. Sensors, gateways and provisioning are IoT-Ignite. Galip Usta v1 needs none of it — the usta is the data source over WhatsApp. Sensor mode arrives later purely as an IoT-Ignite adapter feeding TimescaleDB.

RLS by sensitivity, Postgres-default

PostgreSQL native row-level security backs the regulated tenants (insurance KVKK, Astra financial/board). TimescaleDB (telemetry), ClickHouse (OLAP) and Qdrant (vectors) sit in the same family. MariaDB remains only as an ARMES/legacy adapter.
