v2 changes from v1: Layer 3 expanded to "Ingestion, Quality & Governance" with 4 new modular components: Soda Core (YAML-based quality validation as Airflow task operators), dbt Core (SQL-based Bronze→Silver→Gold transformations, per-UC projects), OpenMetadata (data catalog, automated lineage, profiling, searchable asset registry for operational handoff), LLM Enrichment Service (AI-powered data curation: document classification, entity extraction, product quality scoring, cross-source ID reconciliation — all via LiteLLM proxy as modular Airflow DAGs). Layer 4 gains internal Medallion structure: Bronze (raw as-ingested), Silver (cleaned, validated, cross-referenced), Gold (business-ready, UC-optimized). All new components are independently replaceable and orchestrated through existing Airflow. Estimated additional effort: 35–45 person-days across A0–A1.
Dashed-border components retained from Microsoft. All other components are open-source, self-hostable, and vendor-independent. Core principle: LLM is a reasoning engine over governed, quality-assured data — never the source of truth.
