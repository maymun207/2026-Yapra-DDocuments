Converged from 3 architectures: CWF (Chat With Factory, existing production system), Web Asistan (B2B product catalog chatbot), and Astra EAIP (Enterprise AI Platform with 4 use cases). Built as Lego: Phase 1 foundation supports Phase 2, Phase 2 supports Phase 3. Nothing gets thrown away. Every component is modular and replaceable. MariaDB Galera as primary DB. Keycloak for auth (Entra ID federation in P3). NiFi as primary orchestrator. 55 components across 10 layers.
Timeline: Phase 1 = Month 1 (1 sprint, 5 people). Phase 2 = Months 2-8 (overlaps with Astra A0-A2). Phase 3 = Months 5-22 (Astra A3-A4 + Stage B). Total: 22 months, ~1,085 person-days, peak 10 FTE.
