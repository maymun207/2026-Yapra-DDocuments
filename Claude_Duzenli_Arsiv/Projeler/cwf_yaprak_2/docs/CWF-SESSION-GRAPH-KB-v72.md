## LESSONS THAT TRANSFER (beyond the numbered laws in v75 §8)

- **A premise block earns its keep in both directions.** S72 caught the
  Architect's own decree; S73 caught the Architect's briefed mechanism.
  Write premises expecting them to be executed against reality, not read.
- **Exonerate before you accuse.** Four layers (new renderer, data shape,
  cap, record) were each proven innocent with a measurement before the
  matcher was read. The refused Operator patch shows the cost of skipping
  this: a plausible fix at the wrong layer converts refusals into
  permissions.
- **Starvation can be protection.** Gemini's 0-tool turns never lied; an
  untaught backend being unreachable saved the day-one adoption read from
  contamination. "Model can't use it" is sometimes the system working.
- **The truth surface is the product's spine, polish is its skin.** The
  demo comparison made this concrete: import the skin (recharts patterns),
  never spend the spine (raw output, evidence strips, honest fallbacks —
  all byte-pinned across the swap).
- **Names are data too.** The plan said ragdocs/ragtoken; the hand typed
  machine-knowledge-base/ragbackend; every log query against the
  placeholder names honestly returned nothing. Record the real names the
  moment a hand diverges from a plan.
- **A same-day "before" screenshot is cheap and priceless.** The morning's
  ugly chart became the uplift's ledger exhibit by evening.
