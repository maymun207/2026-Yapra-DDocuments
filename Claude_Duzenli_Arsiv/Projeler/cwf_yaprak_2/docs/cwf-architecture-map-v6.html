INV

Cross-cutting invariants — the red thread

these have each prevented a real bug
Empty ≠ Zero

Barcodeless zone → empty tool result. Agent says "not visible in ARMES", never sıfır/zero. Prompt + gated at publish + validated at runtime (Mode A).

Scope ≠ Title (but datasource is a claim)

Scope = the bound datasource, never the resource title. A "KB7" dashboard on Granit data is Granit. But the datasource field is self-reported → catches an honest mislabel, not a forged-label liar.

Unknown → Floor

Trust is earned, not granted. A backend with no declaration / tier unverified is never authoritative. Known ≠ declared — even ARMES/Superset sit at the floor until seeded.

Gate is unbypassable

published set only by service-role publish() after schema→referential→behavioral. RLS denies any client publish (42501).

RLS isn't enough (RULE 11)

RLS-on + no policy silently no-ops anon UPDATE/DELETE. Classify each table's write-model + REVOKE at the privilege layer for a deterministic 42501.

Trust is a function, not a vibe

Trust = f(provenance, role-ceiling, scope, authority, reconciliation, invariants) — deterministic, auditable. Never an LLM self-score (theatre). Software contains; redundancy reveals.
