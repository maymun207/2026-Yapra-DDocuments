### Rev Gantt chart design (pre-decided)

`RevGanttChart.tsx` replaces `RevGanttTable.tsx`. The surrounding section heading (`t.t2` from `STRINGS[lang].rplan`) and lede (`t.l2`) stay exactly as they were in `RevGanttTable.tsx` — copy them verbatim.

**Bar chart structure:**

```
[month axis ticks:  M0    M2    M4    M6   ... Mmax ]
Phase 1  [══════════████████████░░░░░░░░░░░░░░░  ] M1–M6
Phase 2  [         ████████████████              ] M2–M4
...
Phase 8  [                   ████████████████████] Mx–My
         [label 20px]  [bar track flex-1]  [range 48px]
```

- **Y**: one row per `REV_GANTT` entry (8 rows), top = Phase 1, bottom = Phase 8.
- **X**: auto-scaled to `totalMonths = Math.max(...REV_GANTT.map(r => r.endMonth))`.
- **Month tick marks**: positioned via `flex` at equal intervals. Generate ticks every 2 months from 0 to `totalMonths`. Each tick: `flex-1 text-center text-xs font-mono text-text3`.
- **Bar positioning**: `position: absolute`, left as percentage, width as percentage.

```ts
const leftPct  = (row.startMonth / totalMonths) * 100;
const widthPct = ((row.endMonth - row.startMonth) / totalMonths) * 100;
```

**Permitted `style={{}}` on bar `div`:**

```ts
style={{
  left: `${leftPct}%`,
  width: `${widthPct}%`,
  borderColor: BOUND_COLOR[row.bound],
  backgroundColor: row.bound === 'cal'
    ? 'transparent'
    : BOUND_COLOR[row.bound] + '22',
  backgroundImage: row.bound === 'cal'
    ? `repeating-linear-gradient(45deg, transparent, transparent 3px, ${BOUND_COLOR[row.bound]}40 3px, ${BOUND_COLOR[row.bound]}40 4px)`
    : undefined,
}}
```

- `impl` (implementation-bound): solid fill at 13% opacity (`color + '22'`), solid border.
- `mix` (mixed): same solid fill pattern, different color.
- `cal` (calendar-bound): no solid fill, hatched `repeating-linear-gradient` overlay at 25% opacity (`color + '40'`), solid border. Matches the hatched pattern used in the original `07_revolutionize_schedule.html` source.

**Bar label**: phase long name inside the bar, truncated if needed. `text-xs font-mono truncate px-2`. Color: `style={{ color: BOUND_COLOR[row.bound] }}`.

**Row structure:**

```tsx
<div className="flex items-center gap-3 h-9">
  {/* Phase short label — left-aligned, fixed width */}
  <div className="w-20 shrink-0 text-xs font-mono text-text3 text-right leading-tight">
    {lang === 'tr' ? row.phaseShortTr : row.phaseShortEn}
  </div>
  {/* Bar track */}
  <div className="flex-1 relative h-7 bg-bg rounded-md">
    <div
      className="absolute top-0 h-full rounded-md border flex items-center overflow-hidden"
      style={{ left: `${leftPct}%`, width: `${widthPct}%`, ... }}
    >
      <span className="text-xs font-mono truncate px-2 leading-none"
        style={{ color: BOUND_COLOR[row.bound] }}>
        {lang === 'tr' ? row.phaseLongTr : row.phaseLongEn}
      </span>
    </div>
  </div>
  {/* Month range — right-aligned, fixed width */}
  <div className="w-14 shrink-0 text-right text-xs font-mono text-text3">
    M{row.startMonth}–{row.endMonth}
  </div>
</div>
```

**Legend**: below the chart, 3 items showing the bound color coding. Reuse the `BOUND_COLOR` values. EN-only labels for now — D0.5c will add STRINGS keys.

```
[■ impl]   implementation-bound (compresses)
[■ mix]    mixed
[▨ cal]    calendar-bound (does not compress)
```

Use the same hatched style on the `cal` legend swatch. Rendered as a `flex gap-6` row of 3 items below the chart.

**`totalMonths` calculation**: compute server-side at the top of the component. Do NOT hardcode.

**Mobile behavior**: the bar chart area must be horizontally scrollable on narrow viewports. Wrap the axis + rows in:

```tsx
<div className="overflow-x-auto">
  <div className="min-w-[480px]">
    {/* axis ticks + bar rows */}
  </div>
</div>
```

## 7. Edge cases

- **Bar too narrow to show label text:** The `overflow-hidden` on the bar div clips the label — `truncate` handles this gracefully. Bars for short phases (1–2 months) may show no text at narrow chart widths. This is acceptable — the month range on the right still identifies the row.
- **`totalMonths` = 0 (data guard):** If `REV_GANTT` is empty or all `endMonth` values are 0, skip the chart and render a `font-mono text-xs text-text3` error note. This should not happen with valid data, but guard anyway.
- **`startMonth === 0` for Phase 1:** Left position = 0% — bar starts at the left edge of the track. Visually correct.
- **EAIP Gantt cross-referencing `PHASES`:** If EAIP Gantt rows reference phase IDs, import `PHASES` from `@/app/_data/phases` server-side and build a `Map<string, string>` of `id → color`. Fallback color: `#6E7681` for unmatched IDs.
- **`RevGanttTable.tsx` section heading copy:** Do not reconstruct the heading from memory — read the actual file in Step 0 and copy the JSX verbatim. The exact STRINGS key and class names matter for visual continuity.
- **Mobile: label width at 375px:** `w-20` (80px) + `w-14` (56px) + `gap-3` (24px) = ~160px overhead. Chart track gets remaining space. At 375px, track is ~215px — adequate for the `min-w-[480px]` inner container to trigger scroll correctly. Verify on Vercel preview.
