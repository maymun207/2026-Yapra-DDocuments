### Agent roster rendering

The `agents` array is a discriminated union. Two rendering paths:

**`kind: 'agent'`:**
```tsx
<li className="flex items-center justify-between gap-3 py-1">
  <span className="text-sm text-text">{agent.name}</span>
  <span className="font-mono text-xs bg-bg border border-border rounded-full px-2 py-0.5 text-text3 shrink-0">
    {agent.llm}
  </span>
</li>
```

**`kind: 'divider'`** (appears in Execution swarm — `v1 specialised` and `v2 cellular`):
```tsx
<li className="pt-3 pb-1">
  <span className="font-mono text-xs tracking-widest uppercase text-text3 border-t border-border block pt-2">
    {lang === 'tr' ? agent.labelTr : agent.labelEn}
  </span>
</li>
```

Dividers are bilingual — `labelEn`/`labelTr` from the `RevAgent` union.

## 7. Style and idiom requirements

- `text-accent-blue` for system card h2 names — Revolutionize visual identity (same as Big Picture `hub` card used `accent-blue`).
- No `style={{}}` anywhere in this stage — `RevSystem` has no color data; all styling is Tailwind token-based. This is the first render stage with zero permitted inline style exceptions.
- Agent LLM badge: `bg-bg border border-border rounded-full px-2 py-0.5 text-xs font-mono text-text3` — neutral, no dynamic colors.
- `RevSystemCard` uses `flex flex-col` so the agent list stretches vertically — cards in the same grid row will be equal height via CSS grid row stretch (default).
- All `rev-arch/` components are server components.

## 8. Edge cases

- **Execution swarm dividers:** The `agents` array for Execution swarm contains dividers mid-array (not at the start). The rendering loop must handle mixed `kind` values correctly — map each entry and branch on `kind`. Do not filter or sort the array.
- **`STRINGS[lang].tabs.rarch` used in two places:** NavTabs already reads it for the tab label; RevArchHero reads it again for the h1. This is intentional — both locations independently read from STRINGS. No shared prop or context.
- **System order:** `REV_SYSTEMS` array order is canonical — do not re-sort alphabetically or by some other attribute.
- **5-item grid:** At `lg:grid-cols-3`, 5 items produce a 3+2 layout with an empty cell. This is correct — do not artificially pad to 6 items.
- **`routing` or `routingnote` contains HTML:** If Step 0 finds markup, `dangerouslySetInnerHTML` applies; the `routingnote` inline-quote style may need to be a `<div>` wrapper instead of `<p>`. Report the approach in PR.
