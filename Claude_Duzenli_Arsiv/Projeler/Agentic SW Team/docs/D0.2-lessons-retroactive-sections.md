## § Prompt-author retrospective (Claude)

**Where the D0.2 prompt failed:**
- §9 edge case on "horizontal overflow on tablet (~768–900px)" set the wrong mental model. The actual overflow zone is `md:` to ~`xl:` (768–1280px+), which is the majority of laptop screens. The prescription (`overflow-x-auto` + scrollbar-hide) treated the symptom (long row) instead of the cause (8 long labels can't fit in one row at normal widths). A correct prescription would have been the three-tier system now in D0.2.1.
- §6 acceptance criteria checked HTTP 200 + content match per route but did NOT include any viewport-width visual check. Headless audit passed; human-visible layout failed. Going forward, acceptance criteria for any layout stage must include explicit viewport-width visual checks at common breakpoints (1920, 1366, 1100, 1023, 375 at minimum).
- §12 model recommendation was treated as binding ("use Sonnet 4.6") when it should have been framed as advisory to the operator. D0.2.1 splits this into `model_recommended` (advisory) and `model_used_actual` (recorded post-execution in lessons.md).

**Where the D0.2 prompt held up:**
- 13-field structure produced consistent artifacts — easy to navigate, easy to diff against D0.1.
- "What NOT to build" section worked again: AG didn't add lucide-react, framer-motion, EN/TR toggle, ESLint, etc., despite the temptation surface being larger than D0.1.
- `'use client'` boundary discipline held: only NavTabs + MobileMenu, Header stayed RSC.
- File layout in §3 was followed exactly; no rogue files appeared.

**Pattern Library entries:**
- #2: RSC/client leaf-level toggle idiom (from AG self-report — keep).
- #3: SSoT-nav-array idiom — single `_lib/nav.ts` consumed by Header + NavTabs + MobileMenu.
- #4 (NEW from this incident): Acceptance criteria for layout work must include explicit viewport-width visual checks, not just HTTP/content audits.
- #5 (NEW from this incident): Lessons.md is three-author by default — AG self-report + Operator review + Prompt-author retrospective. Single-author lessons.md is unreliable due to self-grading bias.
- #6 (NEW from this incident): Stage prompt `model` field is advisory; substitution log lives in lessons.md.
