## 7. Style and idiom requirements

- Server components by default. `'use client'` only if and when truly needed (it isn't here).
- Tailwind utility classes only — no inline `style={}`, no CSS modules. Single allowed exception: SVG `stroke` / `fill` attributes can use the CSS variable form `stroke: var(--accent-blue)` if Tailwind utilities don't apply cleanly to SVG geometry.
- TypeScript strict — no `any`, no `unknown` without narrowing.
- Import strings as `import { STRINGS } from '@/app/_data/i18n'`. Within Big Picture components, store the slice locally: `const t = STRINGS.en.big;`. Easier diffing during the future TR work.
- File naming: PascalCase components (`BigPictureHero.tsx`), kebab-case directories (`big-picture/`).
- One default export per component file; types co-located in same file when component-specific.

## 8. Edge cases

- **`note` HTML rendering safety.** `STRINGS.en.big.note` contains `<b>` only (no scripts, no event handlers, no `href`s). Trusted source. `dangerouslySetInnerHTML` is acceptable here. Do not add a sanitizer library. The render path is: `<div role="note"><div dangerouslySetInnerHTML={{__html: t.note}} /></div>`.
- **`substrateitems` separator.** v6 source uses ` · ` (space, middle-dot, space). Split on that exact sequence. Trim each result. If any item is empty after splitting (shouldn't happen but defend against it), filter it out.
- **`hubsub` and `eaipsub` length.** Both are 1-sentence taglines with `·` separators internally. Render as a single line with overflow handling — wrap on narrow viewports, do not truncate.
- **`lede` length on mobile.** The lede is one ~80-word paragraph. At 375px viewport it will span ~7–9 lines. Use `text-base md:text-lg leading-relaxed` so it stays readable. Do not introduce a "read more" cutoff.
- **SVG arrow scaling.** The loop SVG sits between the two cards. Use a fixed `viewBox` and `width="100%" height="auto"` so it scales with the card row. On viewports where cards stack (`<md:`), hide the SVG entirely (`md:block hidden`) and use a small inline indicator instead.
- **Title `"How it fits together"` vs page heading.** The h1 should be `STRINGS.en.big.title`. Do NOT use a static string. This makes D0.3b.1 (TR toggle) a one-line change.
