## 4. Detailed task

### Step 1 — Nav source of truth

`app/_lib/nav.ts`:

```ts
export type NavItem = { label: string; href: string };

export const NAV_ITEMS: readonly NavItem[] = [
  { label: "Big Picture",                 href: "/" },
  { label: "EAIP Architecture",           href: "/eaip/architecture" },
  { label: "EAIP Connectivity",           href: "/eaip/connectivity" },
  { label: "EAIP Schedule",               href: "/eaip/schedule" },
  { label: "Revolutionize Architecture",  href: "/revolutionize/architecture" },
  { label: "Revolutionize Connectivity",  href: "/revolutionize/connectivity" },
  { label: "Revolutionize Schedule",      href: "/revolutionize/schedule" },
  { label: "Bridge & Charter",            href: "/bridge" },
] as const;
```

Every nav component imports from here. Adding a tab later = one edit.

### Step 2 — Header (Server Component)

`app/_components/Header.tsx`: sticky top bar, `bg-bg2/80 backdrop-blur border-b border-border`. Left side = wordmark `TheBluePrint23` with the `23` in `text-accent-blue`, linked to `/`. Right side = `<NavTabs />` on `md` and up, `<MobileMenu />` below `md`. Z-index 50.

### Step 3 — NavTabs (Client Component)

`app/_components/NavTabs.tsx` starts with `'use client'`. Imports `usePathname` from `next/navigation`. Renders `NAV_ITEMS` as a horizontal flex row of `<Link>` elements. Active item (where `pathname === href`, or `pathname.startsWith(href + "/")` for nested) gets `text-text` + `border-b-2 border-accent-blue`; inactive gets `text-text2 hover:text-text`. Compact font size (`text-sm`), `whitespace-nowrap`, horizontal scroll allowed at narrow viewports between `md` and the hamburger breakpoint.

### Step 4 — MobileMenu (Client Component)

`app/_components/MobileMenu.tsx` starts with `'use client'`. State: `const [open, setOpen] = useState(false)`. Renders a hamburger button (inline SVG, three lines, 24×24, `aria-label="Open navigation"`, `aria-expanded={open}`). When `open`, renders a dropdown panel below the header (`absolute`, full width, `bg-bg2`, `border-b border-border`) listing `NAV_ITEMS` vertically. Tapping any link closes the panel (`onClick={() => setOpen(false)}`). Active item highlighted the same way as desktop. Close on `Escape` key (add a `useEffect` keydown listener).

### Step 5 — Root layout update

`app/layout.tsx`: render `<Header />` once above `{children}`. Body class becomes `bg-bg text-text min-h-screen antialiased`.

### Step 6 — Placeholder pages

Each new `page.tsx` exports a server component identical in shape:


## 8. Style and idiom requirements

- TypeScript strict mode preserved; zero `any`, prefer `unknown` + narrowing
- Tailwind utility classes only — no inline `style={}`, no CSS modules
- Server Components by default; `'use client'` only on `NavTabs` and `MobileMenu`
- `next/link` for all internal navigation — never raw `<a href>` for in-app routes
- File naming: kebab-case for route directories, PascalCase for components, camelCase for utilities
- Imports via `@/*` alias
- Components export default; named exports for utilities and types
- Accessibility: every interactive element must have a visible focus ring (Tailwind `focus-visible:ring-2 focus-visible:ring-accent-blue focus-visible:outline-none`); the hamburger button needs `aria-label` and `aria-expanded`

## 9. Edge cases to handle explicitly

- **Active highlight on nested routes:** `pathname === "/"` for home, otherwise `pathname === href || pathname.startsWith(href + "/")`. Without the `+ "/"` guard, `/eaip/architecture` will also light up `/eaip` if it ever exists.
- **`'use client'` boundary:** only `NavTabs.tsx` and `MobileMenu.tsx` start with the directive. `Header.tsx` stays a server component and imports both — this is supported and is the right boundary (keeps server-rendered HTML maximal).
- **Mobile dropdown z-index:** must sit above page content (`z-40`) but below any future modal layer; header itself is `z-50`.
- **Horizontal overflow on tablet (~768–900px):** 8 tabs may overflow on narrower desktop widths. Allow `overflow-x-auto` on the tab row container with `scrollbar-width: none` + `::-webkit-scrollbar { display: none }` (in `globals.css`) so the row scrolls invisibly rather than wrapping.
- **`usePathname()` returns `null` on first render in edge cases:** guard with `pathname ?? ""` before comparison to avoid TS complaints under strict mode.
- **Close mobile menu on route change:** when `pathname` changes inside the open menu, `setOpen(false)` via `useEffect([pathname])`. Otherwise tapping a link navigates but leaves the panel open behind the new page.
