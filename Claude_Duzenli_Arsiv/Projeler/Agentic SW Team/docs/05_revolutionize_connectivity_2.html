Invariants enforced by this wiring: the agent never waits for telemetry (emission is fire-and-forget into the mmap ring buffer); PII and secrets are redacted at emission and full prompts live only in the hash-referenced artifact store; secrets are Vault references only; capability access is allowlist (not denylist), enforced at MCP-server boot from the Keycloak JWT; and no agent has production write access by default — shadow agents are read-only.
