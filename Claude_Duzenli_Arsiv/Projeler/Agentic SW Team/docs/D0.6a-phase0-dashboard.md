## 3. Context

### Architecture decision: hardcoded repo path

`agbuilder-platform/revolutionize` is hardcoded as a constant in `app/_lib/github.ts`. Not an env var. Justification: it's a stable path, not a secret, and the dashboard is purpose-built for this single repo. If we ever fork or stage, refactor to env var then.

### GitHub fetch pattern (server-side only)

```tsx
// app/_lib/github.ts
const GITHUB_REPO = 'agbuilder-platform/revolutionize';
const GITHUB_API = 'https://api.github.com';

export async function fetchManifest(): Promise<Phase0Manifest | { error: string }> {
  const token = process.env.GITHUB_PAT;
  if (!token) return { error: 'GITHUB_PAT env var missing' };

  const url = `${GITHUB_API}/repos/${GITHUB_REPO}/contents/docs/phase0/manifest.json`;
  try {
    const res = await fetch(url, {
      headers: {
        Authorization: `Bearer ${token}`,
        Accept: 'application/vnd.github.raw',
      },
      next: { revalidate: 60 },  // cache 60s — Next.js fetch cache
    });
    if (!res.ok) return { error: `GitHub API ${res.status}: ${res.statusText}` };
    const data = await res.json();
    return data as Phase0Manifest;
  } catch (e) {
    return { error: `Fetch failed: ${e instanceof Error ? e.message : String(e)}` };
  }
}
```

`Accept: application/vnd.github.raw` returns the file content directly as JSON, not the GitHub-wrapped `{ content: base64, ... }` envelope. This is the simpler path.

`next: { revalidate: 60 }` caches the response for 60 seconds — enough to absorb a refresh storm during demos, low enough that document edits show up within a minute.

The function is `'server-only'` — never imported in a client component.


## 7. Edge cases

- **GitHub API rate limit:** Authenticated requests get 5000/hour per token. Even with `revalidate: 60`, normal usage is well under limits. No special handling needed.
- **Manifest version mismatch:** If `manifest.version !== '1'`, log a console warning but still render. The schema may evolve; future versions add fields without breaking the v1 shape.
- **Item with unknown type:** If `item.type` is not in `{document, infra-check, event}`, render with a default `❓` icon and `text-text3` styling. Do not crash.
- **Item with unknown track:** Should not happen (manifest validates this) but if `item.track` is not `A`/`B`/`C`, exclude from rendering and log a console warning.
- **Empty manifest items array:** Render the hero + 3 empty track sections + footer. Each track section shows `(0 items)` count.
- **Network failure / GitHub 5xx:** Error state renders with the actual error message in the detail block.
- **PAT expiration:** GitHub returns 401. Error state shows `"GitHub API 401: Unauthorized"` — operator's signal to rotate the PAT.
- **TR translation of EN-only manifest content:** Stay EN per the rule. The mixed feel (Turkish UI chrome around English technical content) is the intentional house pattern from D0.5e.
