## 1. Goal

Make every component row in `/eaip/architecture` clickable. After D0.4d:

- Clicking a component row expands an inline detail panel immediately below it showing: `component.desc`, `component.notes` (if present), and a compact inbound/outbound connections list (cross-referenced from `EAIP_CONNECTIONS` by component name).
- Clicking the same row again, or clicking another row, collapses the open panel.
- The layer grid remains visible — no overlay, no drawer, no route change. Inline only.
- `EaipArchHero.tsx` and `EaipArchNote.tsx` are server components, **unchanged**.
- `LayerGrid.tsx`, `LayerSection.tsx`, `ComponentRow.tsx` are deleted — replaced by a single `LayerGridClient.tsx` (`'use client'`) that inlines all three as internal functions.
- **This is the final D0 stage.** D0 is complete after this merges.

### Click behavior

```tsx
// ComponentRow button onClick:
onClick={() => setSelectedId(prev => prev === component.id ? null : component.id)}
```

Toggle: clicking an already-open component closes it. Clicking a different component closes the previous and opens the new one (only one open at a time — `selectedId` is a single string).

### Inline expansion layout

```tsx
<li key={component.id}>
  <button
    onClick={() => setSelectedId(prev => prev === component.id ? null : component.id)}
    className={`w-full flex items-center gap-2 py-2 px-2 rounded-lg text-left transition-colors
      ${selectedId === component.id ? 'bg-bg2' : 'hover:bg-bg2'}`}
    aria-expanded={selectedId === component.id}
  >
    {/* component name + phase badge + adapt indicator — same visual as D0.3c */}
    {/* add a small chevron: rotate-0 (collapsed) / rotate-90 (expanded) */}
```

Sub-components (`component.subOf`) get extra indent (`ml-12`/`ml-14`) to align under their parent's existing indentation.

**Chevron:** Add a small `text-text3` chevron character (`›`) or SVG arrow to the button that rotates when expanded. Inline SVG (4 lines) preferred — no icon library. `className={selectedId === component.id ? 'rotate-90' : 'rotate-0'} transition-transform`.

**ConnType badge in detail panel:** Same `style={{}}` exception — `color`, `borderColor`, `backgroundColor` from `connType.color` + hex opacity. Same badge class as D0.3d/D0.4b.

**Section labels:** EN-only hardcoded. "Description", "Notes", "Outbound", "Inbound" — no STRINGS key exists for these. Document as known limitation in lessons.md.

**Empty connections:** If a component has no connections in `EAIP_CONNECTIONS`, omit the Connections section entirely (don't show empty headers).

### Keyboard accessibility

```tsx
// On the button element:
onKeyDown={e => {
  if (e.key === 'Escape' && selectedId === component.id) {
    setSelectedId(null);
    e.stopPropagation();
  }
}}
```

Escape key on an open component collapses it. Standard accessible toggle button behavior — `aria-expanded` already covers screen reader state.

## 7. Edge cases

- **`conn.from`/`conn.to` are IDs not names (if Step 0 reveals this):** Replace `c.from === component.name` with `c.from === component.id`. Report in PR body — this affects the connection lookup logic throughout.
- **Component with 0 connections:** Omit the Connections section entirely — no empty headers.
- **`component.notes` is empty string (not undefined):** Only render the Notes section if `component.notes && component.notes.trim()`.
- **`sortComponents` verbatim copy:** Do not simplify or refactor. The ordering (parents first, children immediately after, orphaned sub-components appended last) was battle-tested in D0.3c. A subtle bug here would break the hierarchy.
- **Sub-component panel indentation:** Sub-components already render with `pl-6 md:pl-8`. Their detail panel adds another level: `ml-12 md:ml-14` (to align with the sub-component text start). Verify visually at 375px — should not create extreme indentation.
- **ConnType not found for connection:** Gray `#6E7681` fallback badge — same as D0.3c/D0.4b patterns.
- **Large `component.desc`:** Some descriptions may be 2-3 sentences. Use `leading-relaxed text-sm` — no truncation, let it wrap naturally.
