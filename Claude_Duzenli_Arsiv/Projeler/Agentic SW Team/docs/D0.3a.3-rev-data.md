## 7. Style and idiom requirements

- `as const` on all top-level data arrays.
- `kebab-case` filenames; `SCREAMING_SNAKE_CASE` for top-level constants (`REV_SYSTEMS`, `REV_CONNECTIONS`, etc.).
- Imports across `app/_data/` use relative paths (`./types`, `./rev-systems`).
- Multi-line object literals for each record; one field per line.
- Preserve Unicode escapes (`\u2019`, `\u2013`) verbatim from v6 source.
- No `any`. If a v6 shape doesn't fit a planned local type, refine the local type — do not cast.

## 8. Edge cases

- **Divider rows inside `RSYS[*].c`:** v6 marks v1/v2 sections inside Execution swarm with `['#', vEnLabel, vTrLabel]`. Model as `{ kind: 'divider' }` discriminated union — do not flatten or drop.
- **Empty `llmTag` values:** some agents in v6 have `''` as the second tuple element (e.g., `['Capability composer','']`). Preserve as empty string in the typed object (`llm: ''`), not `undefined` or omitted.
- **`stageCount: 'TBD'`** appears on Phase 1 group `1.6` (First product, gated by OPEN #1). Preserve as the string `'TBD'`; the type uses `string` (not `number`) intentionally.
- **`RGRP_P1` patch annotations:** the 7th, 8th, 9th tuple elements (`patchEn`, `patchTr`, `kind`) are `''` for non-patched rows. When `kind === ''`, omit `patchEn`/`patchTr` from the typed record entirely (use optional fields). When `kind === 'patch'` or `'open'`, populate them.
- **RCONN `to` values that aren't agent names:** these are external surfaces (LLM providers, MCP servers, Postgres, Redpanda topics). They're not in the agent set — that's correct, not a bug. AG reports the list in lessons.md for design visibility but doesn't try to "fix" them by adding stub agents.
- **`RPH` starts at Phase 2:** v6 doesn't include Phase 1 in `RPH` because Phase 1 has full stage-level detail in `RGRP_P1`. Do NOT add a synthetic Phase 1 entry to `REV_PHASES`. The two arrays carry different abstraction levels intentionally.
- **`RCTYPES['IN-PROC']` with hyphen:** the key contains a hyphen, requiring quoted property access in JS. TypeScript handles this fine in a union literal (`'IN-PROC'`). Preserve the hyphen — don't rename to `'IN_PROC'` or `'INPROC'`.
