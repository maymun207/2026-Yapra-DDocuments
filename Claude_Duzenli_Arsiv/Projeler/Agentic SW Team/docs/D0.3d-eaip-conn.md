- A template with a placeholder: render the count inline.

Report the actual value and chosen strategy in the PR description.

## 7. Style and idiom requirements

- Same dark-theme conventions as D0.3b/D0.3c: `bg-bg` page, `bg-bg2` card/table-row accents, `border-border` separators.
- Table cells: `py-3 px-3 text-sm border-b border-border` — uniform padding, border-bottom per row.
- Table header cells: `font-mono text-xs uppercase tracking-widest text-text3 py-2 px-3 border-b border-border`.
- `overflow-x-auto` wrapper: no extra horizontal scrollbar on desktop (table fits at `max-w-6xl`). At narrower viewports the wrapper provides horizontal scroll.
- `min-w-[720px]` on the `<table>` to prevent column collapse at medium viewports.
- ConnType key grid: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-3`.
- Permitted `style={{}}`: ConnType and Phase badge colors only, in `ConnRow.tsx` and `ConnTypeKey.tsx`. All other styling Tailwind.
- TypeScript strict: all field accesses use verified names from Step 0. No `any`.

## 8. Edge cases

- **`proto` field absent or empty string:** render `—` (`text-text3`) in that cell. Do not render blank.
- **ConnType not found for a connection:** `ct` is `undefined`. Fallback: gray badge (`#6E7681`) with the raw type string as label. Log a console.warn in dev only (no effect on prod build). Report any such fallbacks in PR description.
- **Phase not found for a connection:** same — gray badge, raw phase string as label. Report.
- **`STRINGS.en.econn.cnt` is a template:** if it contains a placeholder (e.g. `{{n}}`, `%d`, `{count}`), replace it with `EAIP_CONNECTIONS.length` using a simple string replace — do not add a template library.
- **Distinct used types count:** if `EAIP_CONNECTIONS` uses fewer than 16 of the 16 EAIP ConnTypes, the type key shows only those used. Correct behavior — do not artificially pad to 16.
- **Very long purpose strings:** some connection purpose strings may be long. `text-sm text-text2` with natural wrapping is correct — do not truncate with `truncate` class. The table columns can expand vertically.
- **D0.3c field name lesson:** Prompt uses `<fieldName>` placeholders in Steps 2–4 intentionally. AG fills these in from Step 0 read results. This is not an error in the prompt — it is a deliberate read-first-then-code discipline.
