### Hub section design

The hub section (`RevConnHub`) is the most distinctive element of this route — a 3-channel architectural overview preceding the detail table. AG reads the actual `colA/B/C` values from Step 0 to determine layout, guided by these principles:

- **If `colA/B/C` are short labels (≤ 5 words)** and `colAsub/Bsub/Csub` are 1-sentence descriptions: render 3 equal-width cards in a row (`grid-cols-1 md:grid-cols-3`), each card showing the label as a `font-semibold` header + the sub as `text-sm text-text2`.
- **If `colA/B/C` are longer** (paragraphs): render as stacked sections with a header + body each.

`hub` + `hubsub` render as: `<h2>` + `<p className="text-text3 font-mono text-sm">` immediately below (hub is the overview heading, hubsub its tagline).

`chTitle` + `chTag`: likely a labeled row describing how channels function. Read actual content; render as a pair: `chTitle` in `font-semibold text-sm text-text` + `chTag` in `font-mono text-xs text-text3 ml-2`.

`stTitle`: may be a standalone label or section header. Read actual content; render at appropriate weight (h3 or `font-mono text-xs uppercase` label depending on length/content).

**Hub visual style:** `bg-bg2 border border-border rounded-xl p-6 md:p-8` outer container. The 3-channel cards inside (if applicable): `bg-bg border border-border rounded-lg p-4`. Accent: `text-accent-blue` for channel labels (Revolutionize palette).

`RevConnRow` (inline function, not exported):
```tsx
function RevConnRow({ conn, connTypes, groups, lang }: {
  conn: RevConnection; connTypes: readonly ConnType[];
  groups: readonly RevGroup[]; lang: Lang;
}) {
  const ct = connTypes.find(c => c.id === conn.type);
  const grp = groups.find(g => g.id === conn.group);
  return (
    <tr className="border-b border-border even:bg-bg2">
      <td className="py-3 px-3 text-sm text-text">{conn.from}</td>
      <td className="py-3 px-3 text-sm text-text">{conn.to}</td>
      <td className="py-3 px-3">
        {/* ConnType badge — same style={{}} exception as D0.3d */}
        <span className="inline-flex items-center rounded-full px-2 py-0.5 text-xs font-mono border shrink-0"
          style={{ color: ct?.color ?? '#6E7681', borderColor: (ct?.color ?? '#6E7681') + '66', backgroundColor: (ct?.color ?? '#6E7681') + '1a' }}>
          {ct?.id ?? conn.type}
        </span>
      </td>
      <td className="py-3 px-3 text-sm font-mono text-text3 break-all">
        {conn.proto || '—'}
      </td>
      <td className="py-3 px-3 text-sm text-text2">
        {lang === 'tr' ? conn.purposeTr : conn.purposeEn}
      </td>
      <td className="py-3 px-3">
        {/* Group pill — neutral, no color data */}
        <span className="font-mono text-xs bg-bg border border-border rounded-full px-2 py-0.5 text-text3 shrink-0">
          {lang === 'tr' ? (grp?.labelTr ?? grp?.labelEn ?? conn.group) : (grp?.labelEn ?? conn.group)}
        </span>
      </td>
    </tr>
  );
}
```

## 8. Edge cases

- **`RevConnection.proto` may be empty string:** render `—` (same as D0.3d). Check whether it is `null`, `undefined`, or `''` — handle all three with `conn.proto || '—'`.
- **`RevGroup` lookup failure:** if `conn.group` has no match in `REV_GROUPS`, render the raw `group` string as the pill label. Report any failures in PR body.
- **`RevConnType` lookup failure:** gray badge `#6E7681` fallback — same as D0.3d.
- **Hub layout ambiguity:** if the actual `colA/B/C` or `stTitle` strings don't fit the specified layout, AG adapts and reports the chosen approach in PR body. Priority: readable, consistent dark-theme aesthetic. Do not leave any of the 17 `rconn` keys un-rendered.
- **All 12 types rendered in key (no filtering):** unlike D0.3d where only used types showed, `REV_CONN_TYPES` was extracted specifically for Revolutionize — all 12 are by definition "used in context." No set intersection needed.
- **`purposeTr` empty or missing for some connections:** if any `purposeTr` is an empty string while `purposeEn` is not, fall back to `purposeEn` for TR render. Report affected connections in PR body.
