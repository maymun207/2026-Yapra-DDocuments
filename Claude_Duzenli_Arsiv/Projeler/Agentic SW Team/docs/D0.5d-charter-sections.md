## 7. Edge cases

- **Unicode escapes:** The data above uses `\u2019` (right single quote), `\u2014` (em dash), `\u2013` (en dash), `\u2192` (arrow). TypeScript handles these at runtime — preserve verbatim in the data arrays.
- **Skill table at 375px:** `overflow-x-auto` + `min-w-[420px]` — table scrolls horizontally on mobile. The description column may be long; `leading-relaxed` and natural wrapping. Do not truncate.
- **`×` in weight column:** Unicode multiplication sign `×` in `'×1'`, `'×2–3'`, etc. Render verbatim — it is already in the source data string.
- **6-item OPENS grid at `md:grid-cols-2`:** 6 ÷ 2 = 3 rows. Clean layout. No spacer card needed.
- **"the same patterns practiced twice" appears in D0.3i `BridgeOverview` lede and in `C_SKILL.noteEn`:** Intentional repetition from the source charter. Do not deduplicate.
