## 1. Goal

Make every agent row in `/revolutionize/architecture` clickable. After D0.5a:

- Clicking an agent row expands an inline detail panel immediately below it showing: agent name, system name, LLM badge, and a compact inbound/outbound connections list cross-referenced from `REV_CONNECTIONS` by agent name.
- Clicking the same row again, or clicking a different row anywhere on the page (including in other system cards), collapses the open panel.
- The system grid remains visible — no overlay, no drawer, no route change. Inline within the card only.
- `RevArchHero.tsx`, `RevRouting.tsx`, `RevArchNote.tsx` are server components, **unchanged**.
- `RevSystemGrid.tsx` and `RevSystemCard.tsx` are deleted — replaced by a single `RevSystemGridClient.tsx` (`'use client'`) that inlines all system + agent rendering plus the detail panel.
- Divider rows (`kind: 'divider'`) are **not** clickable — rendered as passive section labels.

### `RevSystemGridClient` internal structure

```tsx
'use client';
import { useState } from 'react';
import type { Lang } from '@/app/_data/types';
// import type only — no runtime data imports
import type { RevSystem, RevAgent } from '@/app/_data/rev-systems';
import type { RevConnection } from '@/app/_data/rev-connections';
import type { RevConnType } from '@/app/_data/rev-conn-types';

interface Props {
  systems: readonly RevSystem[];
  connections: readonly RevConnection[];
  connTypes: readonly RevConnType[];
  lang: Lang;
}

export default function RevSystemGridClient({
  systems, connections, connTypes, lang
}: Props) {
  const [selectedAgent, setSelectedAgent] = useState<string | null>(null);
  // single state — one agent open at a time across ALL system cards

  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
      {systems.map(system => (
        <SystemCard
          key={system.id}
          system={system}
          connections={connections}
          connTypes={connTypes}
          selectedAgent={selectedAgent}
          onSelectAgent={(name) =>
            setSelectedAgent(prev => prev === name ? null : name)
          }
          lang={lang}
        />
      ))}
    </div>
  );
}

// Inner functions (not exported):
function SystemCard(...) { ... }
function AgentDetail(...) { ... }
```

`selectedAgent` is a global string — clicking an agent in System A automatically collapses any open agent in System B. Toggle: clicking an already-open agent closes it.

### Agent row click behavior

```tsx
// Inside SystemCard, for each agent entry:
// Dividers: render as passive label (no button, no onClick)
// Agents: render as a <button>

onClick={() => onSelectAgent(agent.name)}
aria-expanded={selectedAgent === agent.name}
```

Pressing **Escape** on a focused expanded agent row collapses it:

```tsx
onKeyDown={(e) => {
  if (e.key === 'Escape' && selectedAgent === agent.name) {
    onSelectAgent(agent.name); // toggles to null
    e.stopPropagation();
  }
}}
```

### Inline expansion layout

```tsx
// Agent <li> inside SystemCard agent list:
<li key={agent.name}>
  <button
    onClick={() => onSelectAgent(agent.name)}
    onKeyDown={...}
    aria-expanded={selectedAgent === agent.name}
    className={`w-full flex items-center justify-between gap-2 py-1.5 px-2 rounded-lg
      text-left transition-colors
      ${selectedAgent === agent.name ? 'bg-bg' : 'hover:bg-bg'}`}
  >
    <span className="text-sm text-text">{agent.name}</span>
    <div className="flex items-center gap-2 shrink-0">
      <span className="font-mono text-xs bg-bg border border-border rounded-full
        px-2 py-0.5 text-text3">
        {agent.llm}
      </span>
      {/* chevron — rotates on expand */}
      <svg
        className={`w-3 h-3 text-text3 transition-transform
          ${selectedAgent === agent.name ? 'rotate-90' : 'rotate-0'}`}
        fill="none" viewBox="0 0 6 10" stroke="currentColor" strokeWidth={2}
      >
        <path strokeLinecap="round" strokeLinejoin="round" d="M1 1l4 4-4 4" />
      </svg>
    </div>
  </button>
  {selectedAgent === agent.name && (
    <div className="mt-1 mb-2 bg-bg border border-border rounded-xl p-4">
      <AgentDetail
        agentName={agent.name}
        agentLlm={agent.llm}
        systemNameEn={system.nameEn}
        systemNameTr={system.nameTr}
        connections={connections}
        connTypes={connTypes}
        lang={lang}
      />
    </div>
  )}
</li>
```

The detail panel sits inside the card, expanding below the agent row. The card grows in height; grid cells in the same row stretch via CSS grid row-stretch (default). This is correct — do not constrain card height.

### `AgentDetail` panel content

```
[Agent name — text-base font-semibold text-text]
[System name (bilingual) — text-xs text-text3 font-mono mt-0.5]
[LLM badge — same neutral badge style as agent row]

Connections   (section, only if any found)
  Outbound (N)
  [type badge] → [conn.to]
  [purpose text — text-xs text-text3]

  Inbound (N)
  [type badge] ← [conn.from]
  [purpose text — text-xs text-text3]
```

**Connection lookup** (using field names confirmed in Step 0):

```ts
const outbound = connections.filter(c => c.from === agentName);
const inbound  = connections.filter(c => c.to === agentName);
```

**Purpose display**: if Step 0 reveals `purposeEn`/`purposeTr`, use `lang === 'tr' ? conn.purposeTr || conn.purposeEn : conn.purposeEn`. If it is a single `purpose` string, display as-is.

**ConnType badge in detail panel:** Same `style={{}}` exception pattern as D0.4b/D0.4d — `color`, `borderColor`, `backgroundColor` (hex + 22-opacity suffix) from `connType.color`. Fallback to `#6E7681` if type not found.

**Section labels:** EN-only hardcoded: `"Connections"`, `"Outbound"`, `"Inbound"`. No STRINGS key exists. Document as known limitation in lessons.md (D0.5c will fix these labels for both D0.4d and D0.5a in one pass).

**Empty connections:** If agent has no connections in `REV_CONNECTIONS`, omit the Connections section entirely — do not render empty headers.

**Divider rows stay passive:**

```tsx
// kind === 'divider' — no button, no onClick
<li className="pt-3 pb-1">
  <span className="font-mono text-xs tracking-widest uppercase text-text3
    border-t border-border block pt-2">
    {lang === 'tr' ? agent.labelTr : agent.labelEn}
  </span>
</li>
```

## 7. Edge cases

- **Agent with 0 connections in `REV_CONNECTIONS`:** Panel renders without any Connections section. Verify there are some agents in this state (e.g., vision-engine-only agents may have no outbound).
- **`conn.to` is an external surface (not an agent name):** Display as-is — these are valid external endpoints (MCP servers, gateway wrappers). No special handling needed.
- **`purpose` empty string vs null/undefined:** Guard: `if (conn.purposeEn?.trim())` before rendering purpose line. If Step 0 reveals a single `purpose` field, guard similarly.
- **`RevConnType` not found for a connection type:** Fallback badge color `#6E7681` — same gray fallback as D0.4b/D0.4d.
- **Card height expansion:** When a detail panel with many connections opens inside a card in a 3-column grid, that card grows taller than its siblings. This is correct and expected — CSS grid row-stretch handles it. Do not cap card height or add scrolling.
- **`systems` array order:** Preserve `REV_SYSTEMS` array order exactly. Do not sort.
- **`agents` array order within a system:** Preserve verbatim. Dividers mid-array (Execution swarm) must render in position — do not filter or reorder.
