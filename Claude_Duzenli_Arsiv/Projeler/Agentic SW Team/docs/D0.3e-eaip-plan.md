### Phase breakdown — data derivation

The phase breakdown section is derived server-side:

```ts
import { PHASES } from '@/app/_data/phases';
import { EAIP_COMPONENTS } from '@/app/_data/eaip-components';

const breakdown = PHASES.map(p => ({
  phase: p,
  count: EAIP_COMPONENTS.filter(c => c.phase === p.id).length,
}));
// Note: EAIP_COMPONENTS has 70 entries (67 top-level + 3 subOf).
// Sub-components have their own phase field — count them as discrete entries.
```

Each phase card renders: phase color badge · phase label (bilingual) · component count · optional percentage of total.

### No table this stage — card grid instead

The phase breakdown is 7 items, not a columnar dataset. Use a responsive card grid (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4`) rather than a `<table>`. This avoids the colgroup complexity of D0.3d and matches the editorial feel of the plan tab (summary view, not tabular data).

If a task/milestone table IS needed (Step 0 branch 1), apply the `<colgroup>` lesson from D0.3d: explicit column widths, `min-w-[Npx]`, `overflow-x-auto` wrapper.

## 8. Edge cases

- **Component count sum ≠ 70:** If `PHASES.map(p => EAIP_COMPONENTS.filter(c => c.phase === p.id).length).reduce((a,b)=>a+b,0)` ≠ 70, some components have a `phase` value not matching any `PHASES` entry. Report the discrepancy in PR body. Render "?" count for unmatched phases.
- **`totalu` is a full string including number:** Render it alone as the headline number — do not double-render by also prepending `EAIP_COMPONENTS.length` or any computed number.
- **`risk` plain text (no HTML):** Render as `<p>` inside the styled callout box — keep the `border-accent-amber` box regardless.
- **7 phase cards in a `lg:grid-cols-4` grid:** 7 does not divide evenly into 4. The last row will have 3 cards (rows: 4 + 3). This is acceptable — do not add an empty 8th card as a spacer.
- **`tasks_th` is a column header string, not a section title:** Read the actual value. If it reads like a table column name (e.g., "Tasks"), it may have been intended as a table header, not a section title. In that case, use it as a `<th>` header in a one-column task list if branch 1 applies, or use it as a section title with the placeholder note if branch 0.
