## 3. Context

### Sub-task A — Nav tab i18n design

The current `NavItem` in `app/_lib/nav.ts` has `label` (EN), `shortLabel` (EN), `href`. To make full labels bilingual without importing the entire `STRINGS` object into the client bundle:

1. `nav.ts` adds `tabKey?: TabKey` to `NavItem`. `TabKey` is a local union mirroring the 7 STRINGS tab keys.
2. `Header.tsx` (already has `lang`) resolves `tabLabels = STRINGS[lang].tabs` on the server and passes it as a plain serializable prop to `NavTabs` and `MobileMenu`.
3. `NavTabs` and `MobileMenu` use `tabLabels[item.tabKey] ?? item.label` for the full-label tier only. Short labels remain `item.shortLabel` (EN).

**Why prop-pass instead of client import of STRINGS:** `STRINGS` is a large constant covering all 6 route string namespaces in both languages. Importing it into a `'use client'` component bundles the entire object client-side. Passing `tabLabels` (the resolved 7-key object for the active lang) from the server keeps the client bundle lean.

**Bridge & Charter fallback:** The 8th nav item has no `tabKey` — `item.tabKey` is `undefined`. `tabLabels[undefined]` → falls through to `?? item.label` → renders "Bridge & Charter" in EN always. No special case needed.

### Sub-task B — EAIP Architecture render design

**Data sources consumed this stage:**
- `EAIP_COMPONENTS: readonly Component[]` — 67 items
- `LAYERS: readonly Layer[]` — 10 items, in L0–L9 order
- `PHASES: readonly Phase[]` — 7 items, each with `{ id, color, labelEn, labelTr }`
- `STRINGS[lang].earch` — `{ lede, lg1, lg2, lg3, note }`

**What renders:**
```
EaipArchHero        — lede paragraph + legend row (lg1, lg2, lg3)
LayerGrid           — 10 layer sections, each with its components
  └ LayerSection    — layer name header + sorted component list
      └ ComponentRow — component name + phase badge + adapt indicator
EaipArchNote        — bottom callout (may contain <b> markup)
```

**Component grouping and sort order within each layer:**
1. Filter `EAIP_COMPONENTS` by `layerId === layer.id`.
2. Top-level components (`!c.subOf`) first, preserving declaration order.
3. Each sub-component (`c.subOf === parent.id`) appears immediately after its parent.
4. If a sub-component's `subOf` parent is not found in the same layer (shouldn't happen, but defend), render it as top-level.

**Phase badge coloring:**
Phase colors are dynamic hex values from `PHASES` (e.g., `#58A6FF`, `#3FB950`). Tailwind cannot express arbitrary data-driven hex values without config extension. Permitted exception for this stage: `ComponentRow` may use `style={{ '--ph-c': phase.color } as React.CSSProperties}` to set a CSS variable, then reference it with Tailwind arbitrary value syntax `text-[var(--ph-c)]` and `border-[var(--ph-c)]`. For the background tint, use `style={{ backgroundColor: phase.color + '1a' }}` (hex + `1a` ≈ 10% opacity). This is the only `style={{}}` use permitted in this stage. Document it in the lessons.md self-report.

**What component data is bilingual vs EN-only:**
- Phase labels: bilingual — `phase.labelEn` / `phase.labelTr` (use `lang`)
- Component names (`component.name`): EN-only — render as-is regardless of `lang`
- Component descriptions (`component.desc`): EN-only — not shown on this route at all (reserved for D0.4 detail panel)
- Component notes (`component.notes`): EN-only — not shown
- Layer names (`layer.name`): EN-only — render as-is
- All `STRINGS[lang].earch.*` keys: bilingual — use `lang`

**`earch.note` HTML check:** Before writing `EaipArchNote.tsx`, AG must read `STRINGS.en.earch.note` from `app/_data/i18n.ts`. If it contains HTML markup (`<b>`, etc.), use `dangerouslySetInnerHTML` — same pattern as `AdrLandingNote`. Report in PR description.

### B2 — Create `app/_components/eaip-arch/LayerGrid.tsx`

Server component. Props: `{ lang: Lang }`.

Imports: `EAIP_COMPONENTS`, `LAYERS`, `PHASES`.

Logic:
```ts
// Group components by layer, preserving LAYERS order
const layerSections = LAYERS.map(layer => ({
  layer,
  components: sortComponents(
    EAIP_COMPONENTS.filter(c => c.layerId === layer.id)
  ),
})).filter(s => s.components.length > 0); // skip empty layers

function sortComponents(components: Component[]): Component[] {
  const parents = components.filter(c => !c.subOf);
  const result: Component[] = [];
  for (const parent of parents) {
    result.push(parent);
    result.push(...components.filter(c => c.subOf === parent.id));
  }
  // Orphaned sub-components (parent not in same layer) appended last
  const placed = new Set(result.map(c => c.id));
  result.push(...components.filter(c => !placed.has(c.id)));
  return result;
}
```

Renders a `<div className="space-y-8 md:space-y-10">` of `<LayerSection>` instances — one per non-empty layer — passing `layer`, `components`, `phases` (filtered from `PHASES` for efficiency), and `lang`.
