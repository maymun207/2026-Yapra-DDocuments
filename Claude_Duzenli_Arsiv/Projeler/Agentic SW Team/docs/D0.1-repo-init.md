## 4. Detailed task

### Step 1 — Initialize Next.js project

```bash
cd <Maymun's projects directory>
npx create-next-app@latest TheBluePrint23 \
  --typescript \
  --tailwind \
  --app \
  --no-src-dir \
  --no-eslint \
  --import-alias "@/*" \
  --use-npm

**Why `--no-eslint`:** V0 keeps tooling minimal; add ESLint in V0.2 if needed.

### Step 2 — Configure Tailwind with dark theme tokens

Replace `tailwind.config.ts` with:

  content: ["./app/**/*.{js,ts,jsx,tsx,mdx}"],
  theme: {
    extend: {
      colors: {
        bg:      "#0D1117",
        bg2:     "#161B22",
        bg3:     "#21262D",
        border:  "#30363D",
        border2: "#444C56",

        text3:   "#6E7681",
        accent:  { blue: "#58A6FF", green: "#3FB950", amber: "#E3B341" },

      fontFamily: {
        sans: ['system-ui', '-apple-system', 'Segoe UI', 'Roboto', 'sans-serif'],
        mono: ['ui-monospace', 'JetBrains Mono', 'SFMono-Regular', 'Menlo', 'monospace'],

    },
  },
  plugins: [],
};

```

## 8. Style and idiom requirements

- TypeScript strict mode (default in create-next-app, do not disable)
- Tailwind utility classes only — NO inline `style={}` attributes, NO separate CSS modules
- React Server Components by default (App Router default); do not mark anything `'use client'` in V0.1
- File naming: kebab-case for routes, PascalCase for components, camelCase for utilities
- Imports: use `@/*` alias (configured by create-next-app)
- No `any` types; if Antigravity is tempted to use `any`, prefer `unknown` + narrowing

## 9. Edge cases to handle explicitly

Things Antigravity tends to miss or get wrong:

- **create-next-app version drift:** Pin Next.js version in `package.json` to `15.x` exactly after install; if create-next-app installs a Next 16 beta, downgrade.
- **Tailwind v4 vs v3:** Tailwind v4 has a different config format. If create-next-app pulls v4, EITHER pin to v3 OR adapt the config example above to v4 syntax. Note in lessons.md which version was used.
- **Vercel build settings:** Default `npm run build` should just work. If Vercel asks for build command override, leave blank (use defaults).
- **node_modules in .gitignore:** Verify `.gitignore` includes `node_modules/`, `.next/`, `.vercel/`. create-next-app should add these; double-check.
- **Repo visibility:** Repo should be PRIVATE on GitHub. If created public by mistake, switch to private before push.
