**Prompt weaknesses identified:**
- Prompt was likely **over-specified for this complexity class**. 350-line prompt for a 2-min single-shot task indicates verbosity beyond what the model needed. For similar-sized stages (UI scaffolding, config files, simple page wiring), prompt can be trimmed to ~50-60% length without losing fidelity.

- Stage size estimate (30-60 min) was wildly off. Need new sizing heuristic: small-scaffold stages = 2-5 min, not 30-60 min. Re-calibrate XS/S/M/L bucket definitions in Pattern Library.

**Surprises:**

**Recommendations for D0.2:**
- **Trim prompt verbosity** by ~40% for similar-complexity stages. Keep §1 (goal), §6 (acceptance), §9 (edge cases) at current density. Reduce §3 (context) and §4 (detailed task) since the model handled them with little need for hand-holding.
- **Keep "What NOT to build" section** (§5) — Antigravity respected it cleanly, this is a load-bearing pattern.
- **Keep §6.1 13-field template structure** — calibration signal preserved. Do not move to lightweight template.
- For D0.2 (layout shell + 8 tab nav): expect 5-15 min actual runtime, not 30-60. If estimate is wrong AGAIN by 10×, formalize the recalibration in Pattern Library.
