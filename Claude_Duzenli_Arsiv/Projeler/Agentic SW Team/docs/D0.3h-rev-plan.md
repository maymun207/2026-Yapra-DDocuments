## 8. Edge cases

- **`patchEn`/`patchTr` optional fields:** Only present when `kind === 'patch'`. TypeScript optional (`patchEn?: string`). Render safely: `{group.patchEn && <span ...>{lang === 'tr' ? group.patchTr : group.patchEn}</span>}`.
- **Phase 1 gantt row with no RevPhase:** `phase === null` for `REV_GANTT[0]`. The `gh.o` cell must not crash on `null`. AG decides: render `'—'`, the string `'see above'`, or the `REV_PHASE1_GROUPS.length` count — report choice.
- **`months` string format:** `'~M2–M4'` — the `~` and `–` (em-dash from `\u2013`) may appear. Render verbatim in `font-mono`.
- **Gantt `phaseLongEn`/`phaseLongTr` may be long:** At 200px column width, long phase names will wrap. Use `text-sm leading-snug` and allow wrapping.
- **`bound` badge label:** `'impl'`, `'mix'`, `'cal'` are EN code identifiers. If `lg1/2/3` Step 0 reveals the legend provides short TR equivalents for these, render the legend label as the badge text. If the legend strings are purely descriptive (not short labels), keep `bound` value as-is.
- **`RevOpens.symbol` encoding:** `'①'`–`'⑤'` are Unicode circled numbers. They render correctly in all modern browsers. Preserve verbatim — do not replace with `(1)` etc.
- **Gantt `startMonth`/`endMonth` are integers:** Format as `M${startMonth}–M${endMonth}`. No zero-padding needed.
