# Setup Task — Create `maymun207/revolutionize` repo with Phase 0 scaffold

> **Type:** One-shot setup task (not a TheBluePrint23 stage — separate repo).
> **Estimated:** 15–25 min.
> **Prerequisite:** `gh` CLI authenticated on the operator's machine with permission to create private repos under `maymun207`.
> **Output:** Live private repo with Phase 0 manifest + 25 stub files committed.

---

## 1. Goal

Create the `maymun207/revolutionize` repo that will be the source-of-truth document store for the dual-platform program. After this task: TheBluePrint23 can fetch a Phase 0 manifest from this repo and render the dashboard.

This is **not** a TheBluePrint23 change. It is a separate repository setup.

## 2. Steps

### Step 1 — Create the private repo

```bash
gh repo create maymun207/revolutionize \
  --private \
  --description "Revolutionize — autonomous agent platform · source-of-truth document store" \

```

### Step 8 — Branch protection on `main`

```bash
gh api -X PUT repos/maymun207/revolutionize/branches/main/protection \
  --field required_status_checks=null \
  --field enforce_admins=false \
  --field required_pull_request_reviews='{"required_approving_review_count":1}' \
  --field restrictions=null
```

### Step 9 — Verify

```bash
# Confirm all 25 files exist
ls docs/phase0/*.md | wc -l         # → 25
cat docs/phase0/manifest.json | jq '.items | length'   # → 25

# Confirm push succeeded
git log --oneline -1                # → initial commit on main

# Confirm branch protection
gh api repos/maymun207/revolutionize/branches/main/protection \
  | jq '.required_pull_request_reviews.required_approving_review_count'  # → 1
```
