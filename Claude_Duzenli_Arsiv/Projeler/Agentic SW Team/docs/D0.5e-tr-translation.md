**Rule 3 — Preserve sentence structure and information density.**
Do not summarize or expand. Each TR sentence should convey the same technical facts as the EN original. `descTr` should have the same paragraph structure as `desc`. `notesTr` should have the same brevity as `notes`.

**Rule 4 — Professional register.**
The existing Turkish strings in `STRINGS.tr.*` use a professional, neutral register — no informal contractions, no overly literary phrasing. Match that register.

**Rule 5 — Sub-component stubs (prometheus, redpanda, falkordb).**
These were added in D0.3a.2.1 with EN `desc` and `notes`. Translate like all others. Their `desc` explains the parent relationship — translate that context faithfully.

### Translation approach: batched in-context

AG translates the 70 entries in **batches of 10** using its own language model capabilities in context. For each batch:

1. Read 10 `{ id, desc, notes }` objects from `eaip-components.ts`.
2. Produce the `descTr` (and `notesTr` where `notes !== ''`) for each.
3. Immediately write those 10 entries' updates to the file before proceeding to the next batch.
4. After all 70 are done, run `npx tsc --noEmit` — correct any type errors before opening PR.

**Do NOT** attempt to translate all 70 in a single LLM context pass — batch at 10 to stay within reliable attention range.

## 7. Edge cases

- **`descTr` contains Turkish characters:** `ğ, ü, ş, ı, ö, ç` — TypeScript and the browser handle these natively in string literals. Do NOT use Unicode escapes for Turkish characters in `descTr`/`notesTr` — use the characters directly for readability. (The existing `\u2019` escapes in other data files were inherited from the JS source HTML — not a house style.)
- **`notes` contains a URL or command-line string:** translate surrounding prose; leave the URL/command verbatim. Example: `"Run kubectl apply -f deploy.yaml to install."` → `"Kurmak için kubectl apply -f deploy.yaml komutunu çalıştırın."`
- **Batch boundary:** if a component at position 10 has context from position 9 (e.g., references its parent component by name), the batch boundary does not matter — each translation is self-contained at the component level.
- **`sub` field is similar to `desc`:** `sub` is a one-line tagline (EN-only, rendered in the component row, not the detail panel). Do not add `subTr`. This is intentional — the architecture grid rows stay EN-only for conciseness.
- **`displayNotes` when `component.notes === ''` and `component.notesTr` is undefined:** the existing guard `{component.notes && component.notes.trim() && (...notes section...)}` should already suppress the notes section. Confirm this guard is in `LayerGridClient.tsx` — if it references `component.notes` directly, update to reference `displayNotes`.
