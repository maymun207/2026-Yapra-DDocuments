STAGE 1

payload conforms — CORE Zod (locked) / SOFT field-spec. Unknown fields rejected.

STAGE 2

pass ▸

INV

Cross-cutting invariants — the red thread

these have each prevented a real bug
Empty ≠ Zero

Barcodeless zone → empty tool result. Agent says "not visible in ARMES", never sıfır/zero. Enforced in the prompt, gated at publish, and (next) validated at runtime.

Gate is unbypassable

published set only by the service-role publish() after schema→referential→behavioral. RLS denies any client publish (42501).

Secrets via env only

Token off the client (proven: body + bundle). Never log a token / service-role key / JWT. Config in dbConstants, not literals.

No vector in the core

The deterministic knowledge slice is typed code/data. IKINCILUST ⇄ IKINCILALT are embedding near-neighbors — vector would corrupt. pgvector gated for a future Layer-2 corpus only.

Learn routing, not facts

Learning improves how the agent finds tools (tool_category_cache). It never changes what it knows (correctness → code or gated).

Trust code, not reports

Each phase independently verifies the prior phase against live source. This map's core is drawn from source, not from the build report.
