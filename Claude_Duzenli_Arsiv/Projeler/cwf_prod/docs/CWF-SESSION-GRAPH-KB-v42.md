## 2 · THE SIX RECONCILER LESSONS (all now permanent fixtures)
1. **argv**: an npm alias with a trailing `--` eats the documented invocation.
2. **F99 dedupe**: multiple archived rows per (kind,key) restore non-deterministically —
   restore ONLY max-version, report the skipped forever.
3. **F100**: phantom sweep must cover annotations, not just categories.
4. **F102 order**: annotations before ANY category — repairs can CARRY additions.
5. **F103 resurrection**: "derive from live" needs archived-with-no-sibling visibility —
   kind-generic (HOTFIX-5+6), or the reconciler is amnesiac about its own step-2.
6. **F104 invariant**: phantom filtering is an INVARIANT on every category payload from
   every door (repair/resurrect/staged) — never a path step.
Meta-lesson: **the gate validating the WHOLE candidate turns one halt into a full X-ray**
— the manual-era curse became the machine-era sensor. And: every halt cost ZERO mutations
or was cleanly resumable; the human-click alternative would have cost weeks and missed two
classes entirely (phantoms, F101).
